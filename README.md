Trabalho B1 - Lógica de Programação e Algoritmos
Descrição
Programa em C que simula o atendimento de uma empresa de entregas: calcula o valor de cada entrega com base em distância, peso, modalidade, proteção e tentativas extras, e no final mostra um resumo da sessão.

Funcionalidades
Calcula o valor da entrega.
Valida todas as entradas.
Processa várias entregas seguidas.
Mostra um resumo final.
Organização da solução
O programa é dividido em funções: leitura dos dados, cálculo do valor da entrega e resumo. A main só faz o desenvolvimento do código.

Compilação

gcc -o sim main.c

Execução

./sim
